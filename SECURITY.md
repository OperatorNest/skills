# Security

Report vulnerabilities privately to operatornest+security@gmail.com. Include the affected file, release, reproduction steps, and likely impact. Remove credentials and personal data from examples. Do not open a public issue with exploit details before maintainers have reviewed the report.

## Scope

Skill instructions, plugin manifests, marketplace catalogs, and validation scripts in this repository are in scope. Reports may cover unintended action authority, unsafe instruction handling, path traversal, or data exposure caused by these files.

Release 1.0.x receives security fixes. Client applications and services maintained by other organizations belong to their own reporting channels. A vulnerability in operatornest.com can be reported to the same private address; identify the affected URL.
