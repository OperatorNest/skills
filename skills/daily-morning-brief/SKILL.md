# Daily morning brief

## Inputs

Ask for the selected calendar, inbox scope, active task list, overnight receipts, previous brief cutoff, priority people and deadlines, workdays, local delivery time and time zone, word limit, and private destination. Use supplied answers before asking again.

## Steps

1. Check only the named sources for work since the last brief. Record check times and access failures.
2. Separate completed outputs, drafts, held actions, and blocked work. A task marked complete needs a receipt or verifiable result before it enters completed work.
3. Check today's commitments, moved meetings, deadlines, and priority requests. Link each material item to a source or receipt.
4. Write four sections: completed, today, decisions waiting, and blocked or unknown. For decisions, name the action and destination and link the full proposal. Keep routine steps in the receipt.
5. Deliver privately to the selected destination. If a source fails, return a partial brief with named gaps; never say an unchecked inbox is clear. If a later check materially changes a claim, deliver a labeled correction through the same authorized route. Keep minor changes in the receipt.

## Approval boundary

The requested private brief may report work and approval requests. It does not approve them. New sends on the reader's behalf, bookings, payments, deletions, and publishing require the human's OK. Sharing the brief beyond the named destination needs approval. Hold an item outside standing rules and show the decision needed.

## Output

Return the four-section brief within the requested limit. Each material item has a source, current status, and relevant time. Name failed or partial checks and any agreed retry time.

Append a receipt: sources and check times, included tasks, held actions, missing evidence, brief version, delivery status and time, and corrections.

## Check against the brief

Confirm completed work has evidence, each held action remains held, changed commitments have current sources, and all missing checks appear as gaps. Check cutoff, word limit, time zone, and destination. If delivery or scheduling tools are unavailable, return the brief here and report those capabilities as unconfigured.
